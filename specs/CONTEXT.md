# Ubiquitous Language (`specs/CONTEXT.md`)

| Canonical Term | Definition |
|---|---|
| **PKHaX Mode** | Permissive ROM-hack-compatible Pokémon save editing mode that performs surgical block edits and checksum recalculation without rejecting custom ROM-hack abilities, moves, types, or base stats. |
| **BEEF Footer** | The 3DS Gen 6 (`XY`/`ORAS`) and Gen 7 (`SM`/`USUM`) save block descriptor table at the end of a decrypted Checkpoint `main` file, tagged with magic `0x42454546` (`"BEEF"`), storing per-block CRC-16 checksums. |
| **LayeredFS Mod** | Luma3DS title replacement directory at `sdmc:/luma/titles/<16-hex-TitleID>/` (containing `romfs/`, `exefs/`, or `code.bin`) used by 3DS ROM hacks. Toggled off by moving to `sdmc:/luma/titles_disabled/<16-hex-TitleID>/`. |
| **SD Snapshot / Diagnostic Log Bundle** | Structured JSON + raw log collection generated by `3ds_sysdash`, `3ds_drop`, or `pc_companion/sd_scanner.py` covering SD free space, Checkpoint/TWiLightMenu/GBA saves, Luma LayeredFS mods, `errdisp.txt`, and Luma ARM9/ARM11 `.dmp` exception headers. |
| **Atomic Save Write** | Writing `<path>.bak` (backup of original), writing modified bytes to `<path>.tmp`, flushing, and calling `rename("<path>.tmp", "<path>")`. |
| **UniqueId** | The 20-bit 3DS Title UniqueId in `meta/app.rsf` (`0x0D3D0` PieceDuel, `0x0D3D1` PokeDash, `0x0D3D2` SysDash, `0x0D3D3` 3DS Drop) ensuring all apps coexist on the 3DS HOME Menu without overwriting each other. |
